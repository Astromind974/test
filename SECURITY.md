## Signaler une vulnérabilité

**Ne créez pas d'issue publique pour signaler une vulnérabilité de sécurité.**

Si vous découvrez une faille de sécurité, veuillez envoyer un message privé via [GitHub Security Advisories](https://github.com/Astromind974/test/security/advisories/new).

Incluez autant de détails que possible :
- Type de vulnérabilité
- Chemin complet du ou des fichiers sources concernés
- Étapes pour reproduire
- Preuve de concept ou code d'exploitation (si possible)
- Impact potentiel

Nous nous engageons à accuser réception de votre signalement dans un délai de **48 heures** et à vous tenir informé de l'avancement du correctif.
